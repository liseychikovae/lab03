# Домашнее задание lab03

Лабораторная работа Лисейчиковой Екатерины

## Что требовалось сделать

Домашнее задание относится к теме лабораторной работы III: изучение систем автоматизации сборки проекта на примере cmake.

## Выполненные пункты

- `formatter_lib` собирается как статическая библиотека `formatter` и предоставляет функцию форматирования строки;
- `formatter_ex_lib` расширяет базовый formatter и линкуется с ним через `target_link_libraries`; 
- `hello_world_application` демонстрирует использование `formatter_ex`; 
- `solver_lib` решает квадратное уравнение и возвращает действительные корни;
- `solver_application` объединяет `solver` и `formatter_ex`, печатая результат в отформатированном виде.

## Как проверить домашнее задание

```bash
cmake -S . -B _build -DCMAKE_BUILD_TYPE=Release
cmake --build _build
./_build/hello_world_application/hello_world
./_build/solver_application/solver_app 1 -3 2
cmake --install _build --prefix _install
```

## Пояснение по реализации

Проект оформлен так, чтобы его можно было перенести в Linux-окружение и собрать стандартными командами CMake. Файлы не завязаны на абсолютные пути macOS, персональные секреты не добавлены в git, а дополнительные инструменты подключаются через конфигурационные файлы конкретной лабораторной.
