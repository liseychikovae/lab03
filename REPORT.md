# lab03

Лабораторная работа Лисейчиковой Екатерины

## Отчет по лабораторной работе III

### Тема

Изучение систем автоматизации сборки проекта на примере CMake.

### Цель работы

Цель работы - перевести учебный C++-проект на автоматизированную сборку CMake и оформить домашнее задание Formatter Inc.

### Используемое окружение

- основной целевой сценарий: Linux;
- язык: C++11;
- система сборки: CMake;
- дополнительные инструменты добавляются по теме конкретной лабораторной;
- персональные токены и временные адреса не сохраняются в репозитории.

### Структура проекта

- `formatter_lib` - базовая статическая библиотека форматирования;
- `formatter_ex_lib` - расширенная библиотека, использующая `formatter`;
- `solver_lib` - библиотека для решения квадратного уравнения;
- `hello_world_application` - демонстрационное приложение;
- `solver_application` - приложение для вывода корней уравнения;
- `tests` - модульные тесты, начиная с lab05;
- `docs` и `scripts` - дополнительные материалы поздних лабораторных.

### Ход выполнения

- создан корневой `CMakeLists.txt` с настройкой стандарта C++11;
- оформлены статические библиотеки `formatter`, `formatter_ex` и `solver`;
- добавлены приложения `hello_world` и `solver_app`;
- настроены include-директории, связи между target и правила установки;
- домашнее задание вынесено в отдельные каталоги библиотек и приложений.

### Команды для проверки

```bash
cmake -S . -B _build -DCMAKE_BUILD_TYPE=Release
cmake --build _build
./_build/hello_world_application/hello_world
./_build/solver_application/solver_app 1 -3 2
cmake --install _build --prefix _install
```

### Домашнее задание

Домашнее задание выполнено внутри этого же репозитория. Подробное описание вынесено в `HOMEWORK.md`.

Кратко по выполнению:

- `formatter_lib` собирается как статическая библиотека `formatter` и предоставляет функцию форматирования строки;
- `formatter_ex_lib` расширяет базовый formatter и линкуется с ним через `target_link_libraries`; 
- `hello_world_application` демонстрирует использование `formatter_ex`; 
- `solver_lib` решает квадратное уравнение и возвращает действительные корни;
- `solver_application` объединяет `solver` и `formatter_ex`, печатая результат в отформатированном виде.

### Результат

Получился базовый CMake-проект, который можно собирать на Linux без ручного вызова компилятора для каждого файла.

В ходе лабораторной работы закреплены практические навыки настройки проекта, автоматизации сборки и оформления результата в виде воспроизводимого репозитория. Работа подписана: Лабораторная работа Лисейчиковой Екатерины.
